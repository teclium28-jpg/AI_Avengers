# India sample dataset (synthetic)

Generated by `python3 scripts/generate_india_dataset.py` (seeded, reproducible).
District names are real; **all quantities are invented** and every row is labeled
`simulated`. Do not present these as real statistics.

- `regions.csv` - 30 districts: demand, capacity, prior dispatch, open/closed (same schema as `docs/data-preparation.md`).
- `stock.csv` - one confirmed stock row (about 70% of what regions can absorb, so there is a real shortage).
- `donations.csv` - supporting donor batches summing to the stock total (not read by the cleaner yet).
- `regions_dirty.csv` - same data with injected errors (missing, negative, non-integer, duplicate, closed-with-capacity, dispatched > capacity, absurd magnitude) to demo the cleaning pipeline.

Edge cases built in: 2 closed regions, 1 zero-demand region, 3 regions with prior dispatch, 4 capacity-bound regions.
